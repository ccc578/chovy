Chovy

一款轻量、离线、打开即用的桌面图像处理软件。替代系统自带画图工具，覆盖裁剪调参、滤镜水印、绘制标注与批量处理，满足你的日常修图需求。

📦 查看源码 🚀 快速开始

六大核心功能

模块间联动，打开即用，操作简单直观，全程本地读写，图片不出你的电脑。

📂

本地浏览与导入

两种打开方式 + 拖拽打开，内置缩略图侧边栏与最近记录。

  • 单张 / 文件夹批量导入，拖拽到窗口直接打开
  • 兼容 JPG / PNG / GIF / BMP / WebP
  • 缩略图网格浏览，点击即切换编辑
  • 自动保存最近编辑记录
🎚️

基础图像调整

几何变换 + 参数调节，滑块拖动实时预览。

  • 自由裁剪，比例预设 1:1 / 16:9 / 4:3 / 证件照
  • 任意角度旋转、90° 步进、翻转、缩放
  • 亮度 / 对比度 / 饱和度 / 色温 / 曝光
  • 一键自动白平衡、对比度、锐化
🎨

滤镜与水印

10 种生活化滤镜 + 文字/图片水印，强度无级可调。

  • 黑白 / 复古胶片 / 冷色 / 暖色 / 高斯模糊等
  • 滤镜强度 0–100% 实时预览
  • 文字水印：字体、字号、颜色、透明度可调
  • 图片水印：logo 大小与透明度任意放置
✏️

绘制与标注

画笔、橡皮、形状与文字标注一应俱全。

  • 画笔（粗细/颜色/透明度）、橡皮擦
  • 矩形 / 圆形 / 直线 / 箭头
  • 可编辑文字框，改字体与颜色
📦

批量处理

统一规则批量处理，后台运行不阻塞主界面。

  • 统一尺寸缩放、格式互转（JPG/PNG/WebP）
  • 批量添加水印
  • 自定义输出目录与命名规则
  • 进度条显示，失败单独提示
🛠️

辅助功能

对比、撤销与导出，让修图更安心。

  • 按住快捷键一键对比原图 / 效果图
  • 最多 20 步撤销 / 重做
  • 导出 JPG / PNG / WebP，可调压缩质量
  • 支持原图覆盖或另存为

快速开始

克隆仓库、安装依赖、运行即可。依赖 PySide6 + Pillow + NumPy。

三步运行

  1. 克隆仓库到本地
  2. 安装依赖 pip install -r requirements.txt
  3. 运行 python run.py，开始修图

💡 离线依赖：若需要把 PySide6 打包到本地目录离线使用，可执行 pip install --target vendor PySide6-Essentials，详见 README。

# 克隆并运行
git clone https://github.com/ccc578/chovy.git
cd chovy
pip install -r requirements.txt
python run.py

# 离线打包 PySide6（可选）
pip install --target vendor PySide6-Essentials
